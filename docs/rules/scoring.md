# Arena 积分（PTS）

名次给底座分，击杀给加成。实现见 `crates/t99-core/src/score.rs`。

## 1. 名次底座

| 名次 | 分数 | 步长 |
|---|---|---|
| 1 | 1000 | — |
| 2 | 850 | −150 |
| 3 | 700 | −150 |
| 4 | 650 | −50 |
| 5 | 600 | −50 |
| 6–10 | 500 → 480 | −5/名 |
| 11–20 | 450 → 414 | −4/名 |
| 21–30 | 400 → 373 | −3/名 |
| 31–50 | 350 → 312 | −2/名 |
| 51–75 | 300 → 108 | −8/名 |
| 76–99 | 100 → 8 | −4/名 |

全部 99 个名次合计 27,451 分，平均 277.3。

## 2. 加成

```
pts = 底座
    + 5 × 击杀数
    + 50 × 首杀
    + 底座 × (1% × 击杀数 + 10% × 首杀)
```

- 百分比按**底座**计算，不用已经加过成的总分，避免循环。
- 首杀同时也是普通击杀，两份额外加成都要算。
- 百分比项最后一次性向下取整。

示例：

| 情况 | 计算 | 合计 |
|---|---|---|
| 1 名，0 杀 | 1000 | 1000 |
| 1 名，20 杀，首杀 | 1000 + 100 + 50 + 300 | 1450 |
| 50 名，5 杀 | 312 + 25 + 15 | 352 |
| 99 名，0 杀 | 8 | 8 |

## 3. 名次规则

| 结束方式 | 规则 |
|---|---|
| 吃鸡（最后一人存活） | 生存者第 1；其余按淘汰时间，晚淘汰者在前 |
| 流局（倒计时耗尽） | **存活者**按击杀数降序，其次徽章数；两者都相同则同名次 |
| 流局中的已淘汰者 | 按淘汰时间，晚淘汰者在前，排在所有存活者之后 |

同名次采用 competition 排名：若 8 人并列第 15，各得第 15 名的底座分，下一名从第 23 名开始。

## 4. 数据来源

`match_result` 的每个席位包含 `rank`、`ko`、`first_ko`、`pts`。其中 `first_ko` 由引擎记录本局第一次由垃圾击倒产生的 KO；同帧多次 KO 取引擎先记录者。
